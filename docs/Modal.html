# <Modal />

Компонент модального вікна, який рендериться через React Portal. Використовується для відображення важливих повідомлень (наприклад, про перемогу) поверх усього іншого контенту.

Parameters:
Name Type Description
props Object

Властивості компонента.
isOpen boolean

Прапорець, що визначає, чи відкрите модальне вікно.
children React.ReactNode

Вкладені елементи (контент), які будуть відображені всередині модального вікна.
