# <Card />

Компонент ігрової картки. Відповідає за відображення однієї картки на ігровому полі, анімацію її перевертання та стан збігу.

Parameters:
Name Type Description
props Object

Властивості компонента.
item Object

Об'єкт з даними картки (інформація про персонажа).
item.content string

URL зображення персонажа.
item.name string

Ім'я персонажа (використовується для alt-тексту зображення).
isFlipped boolean

Прапорець: чи перевернута картка лицьовою стороною догори.
isMatched boolean

Прапорець: чи знайдена вже пара для цієї картки.
onClick function

Функція-обробник, яка викликається при кліку на картку.
